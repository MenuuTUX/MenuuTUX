## Featured: Portfolio Compass

<a href="https://portfolio-compass.vercel.app">
  <img src="https://raw.githubusercontent.com/MenuuTUX/Portfolio-Compass/main/docs/screenshots/01-landing.png" alt="Portfolio Compass landing page" width="100%">
</a>

A free planning tool for people who have just opened a TFSA. Check contribution room, compare stocks and ETFs, build a portfolio, and backtest ideas, all in the browser with no login and no server database.

- **Compass Lab:** a backtesting workspace with guided, no-code and code modes (Python via Pyodide, or TypeScript). Orders fill at the next bar's open, and every result shows a first-70% versus last-30% split.
- **Honest numbers:** every figure shows its assumptions, and every projection says what it is not.
- **Engineering:** Next.js, TypeScript and Bun, with 1,000+ unit tests and typecheck, lint and tests on every pull request.
